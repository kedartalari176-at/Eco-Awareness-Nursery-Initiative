# 🌱 Grow Green, Live Green

## Nursery Plant Awareness System

**Grow Green, Live Green** is a responsive web project designed to create awareness about nursery plants, their importance, proper plant care, gardening, and environmental protection.

## 🎯 Project Objective

The main objective of this project is to educate people about plants and encourage them to grow, protect, and care for plants to create a greener and healthier environment.

## ✨ Features

- 🌱 100+ Plant Varieties
- 💧 Plant Care Tips
- 🌿 Plant Categories
- 🌍 Environmental Benefits
- 🌳 Gardening Guide
- 💡 Plant Care Awareness
- 📊 Project Statistics
- 📱 Responsive Design
- 📨 Contact Form
- 🎨 Modern Green-Themed UI

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🚀 How to Run

1. Download or clone the project.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. The website will start running.

### Using CodePen

1. Open CodePen.
2. Create a new **Pen**.
3. Paste HTML into the HTML panel.
4. Paste CSS into the CSS panel.
5. Paste JavaScript into the JS panel.
6. Save the project and view the live preview.
